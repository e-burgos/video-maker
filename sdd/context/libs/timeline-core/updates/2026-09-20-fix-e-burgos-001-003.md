# FIX-e-burgos-001-003 — 2026-09-20

## Estado
La `Timeline` puede declarar con qué placa de marca abre y cierra el video:
`bumpers?: { intro?: LogoBumper; outro?: LogoBumper }`, aditivo y opcional. `durationFrames` **no
cambia de significado**: sigue siendo el contenido, y la duración total del video la calcula
`timelineTotalFrames`.

## Estructura
- `schemas/timeline.schema.ts`: `LogoBumperSchema` (`enabled` default false, `durationMs` entero
  500–6000 default 2000, `backgroundColor` hex `#rrggbb` default `#ffffff`, `animation`
  `fade|zoom|slide-up` default `zoom`, `logoWidthRatio` (0,1] default 0.4), `TimelineBumpersSchema`,
  `HexColorSchema` y las constantes de default. JSON Schema regenerado (`timeline`).
- `timeline/bumper-frames.ts`: `logoBumperFrames`, `introBumperFrames`, `outroBumperFrames` y
  `timelineTotalFrames` — puras, `round(durationMs / 1000 * fps)`.
- `timeline/validate-timeline.ts`: `timelineWarnings(timeline)` devuelve `TimelineWarning[]` con el
  código `BUMPER_WITHOUT_LOGO`. Es un **aviso**: `validateTimeline` no lo reporta y su contrato
  (`{ ok: true } | { ok: false; issues }`) no cambió, así que no bloquea ni guardado ni render.
- La lista cerrada de `schemas.spec.ts` (CA-016) se amplió con los nuevos valores públicos.

## Dependencias
Ninguna.

## Qué sigue
El bumper dibuja el logo de `timeline.logo`; no tiene asset propio. Si alguna vez hace falta una
placa con otra imagen, el campo nuevo va en `LogoBumper`, no en `LogoOverlay`.
