# FIX-e-burgos-008-001 — 2026-09-11

## Estado
El agente de IA nunca se invoca sin `--model`: `CLAUDE_CLI_MODEL` tiene default `sonnet` y
`AiAgentConfig.model` dejó de ser nullable. `AI_AGENT_FAILED` publica el detalle del proveedor
(`subtype` y `result`, recortados a 600 caracteres) y un `hint` que nombra `claude update` cuando el
`result` menciona `claude_code_version_too_old`; el marcador de cuota sigue teniendo prioridad y mapea a
`AI_AGENT_RATE_LIMITED`. `POST /projects/:slug/jobs` acepta `model?` en los jobs `storyboard` y `voice`.

## Estructura
`AiAgentRequest` gana `model?: string | null` y `claudeCliArgs` resuelve `request.model ?? config.model`.
Módulo nuevo `jobs/job-model-params.ts` (`parseJobModel(value, allowed)`), usado por el `jobs-handler`
contra `runtime.producer.models`. `CreateStoryboardJobInput`, `StoryboardJobRecord` y
`StoryboardPipelineRequest` llevan `model: string | null` hasta el puerto del agente; el job `voice` valida
el campo y lo descarta (la síntesis es local).

## Dependencias
Código de error nuevo `JOB_MODEL_INVALID` (422). `RenderApiErrorDetails` y `RenderApiErrorPayload` ganan
`subtype?: string` y `result?: string`. Sin dependencias npm nuevas.

## Qué sigue
El payload de `AI_AGENT_FAILED` ya puede nombrar rutas absolutas de la máquina si el proveedor las escribe
en `result`: es un canje deliberado para un studio self-hosted, documentado en el README de la app.
