# FIX-e-burgos-005-001 — borrado de assets (2026-09-11)

## Qué pasó
El `?force=true` de `DELETE /projects/:slug/assets/:role/:filename` nunca llegaba al handler:
`toRequestLine` armaba el `path` con `new URL(incoming.url).pathname`, que descarta el query string.
El test unitario del handler pasaba porque le inyecta la ruta `'/…?force=true'` a mano, y el del
helper `queryFlag` porque parsea strings. Los dos verdes, la feature rota. Lo descubrió el E2E, en el
último paso, después de pagar arranque de API + vite + Chrome.

## Lección
Un parámetro que viaja en la URL se verifica contra el **servidor real** (un test que levanta el
socket y compara el caso con flag contra el caso sin flag), nunca contra el handler con la ruta
escrita a mano: entre el socket y el handler hay un parser que puede estar tirando el dato.

## Costo evitable
Una corrida E2E completa (~70 s más el arranque de Chrome) y el rearmado del guion. Un test de
servidor de 20 líneas —el que quedó— lo hubiera dicho en 2 s, y era escribible antes del E2E porque
el contrato ya nombraba el query param.
